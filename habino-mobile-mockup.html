Design approach
Airbnb-inspired UX with Habino's brand identity. Light mode, clean cards, generous whitespace.
AI Search
Smart search bar — 3 states
Default → placeholder. Focused → live AI typing indicator + suggestion dropdown with recent searches. Loaded → compact results chip. See "AI Search States" screen.
UX Pattern
Listing / Map toggle
Pill toggle below search bar. Listing = full-card scroll. Map = immersive full-screen map with floating price pins and bottom sheet preview carousel.
Visual System
Property cards — Airbnb DNA
230px tall image with rounded-28px corners, photo carousel dots, contextual badges (Rent/Buy/New), heart save button, clean info hierarchy below.
Architecture
5-tab bottom nav
Explore · Wishlist · Market · Messages · Profile. Persistent across all screens. Active state: violet icon + bold label. Unread badge on Messages.
From mockup → real app
1
Next.js + React Native (Expo) — Share business logic, split presentation layer for web and mobile.
2
Map integration — Mapbox GL JS or Google Maps with real property coordinates from Supabase PostGIS.
3
AI search — Connect search bar to Claude API with streaming. Real-time suggestion generation.
4
Design tokens — Export CSS variables to a shared design token package (Style Dictionary) for web + mobile parity.
5
Animations — Framer Motion (web) / Reanimated (native) for card swipes, toggle transitions, search bar expansion.
